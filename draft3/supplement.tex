\section*{Supplementary note S3: files and reproduction}
Everything below is in the project repository; commands run from the Paper3 folder.
\begin{itemize}
  \item Frozen plan and freeze record: docs/CONFIRM3\_PLAN.md and docs/FREEZE3.md (tag confirm3-freeze).
  \item Confirmation run: python -I src/p3/confirm3.py data/clean/usgs\_new3\_2024 confirm3 data/clean/usgs\_new3\_2024.md5; outputs in results/confirm3 (verdicts3.md and verdicts3.csv).
  \item Results write-up: docs/CONFIRM3\_RESULTS.md.
  \item Tables and figures of the manuscript: python -I src/paper/tables5.py, src/paper/region5.py, src/paper/make\_figures5.py, and src/paper/supplement5.py.
  \item Checks: python -I src/paper/check\_draft.py draft3 and python -I src/paper/check\_numbers5.py.
\end{itemize}
