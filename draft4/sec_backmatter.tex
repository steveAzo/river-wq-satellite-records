\section*{Software and data availability}
\begin{itemize}
\item Name: river-wq-satellite-records, version v3.0.0.
\item Developers: Stephen Kwaku Azongo and Kofi Sarpong Adu-Manu, Department of Computer Science, University of Ghana.
\item Contact: the corresponding author.
\item Year first available: 2026.
\item Language and requirements: Python 3.13 (packages listed in requirements.txt); a standard personal computer with 4 GB of memory runs every script.
\item Size: about 17,000 lines of analysis code and 3,200 lines of tests.
\item Licence: MIT for the code; CC BY 4.0 for the derived data and results.
\item Repository: https://github.com/steveAzo/river-wq-satellite-records; archive: https://doi.org/10.5281/zenodo.23617664 (all versions; version v3.0.0 accompanies this article).
\item Data: the USGS records were obtained from the National Water Information System and are in the public domain; the cleaned records, the sealed cohort with its checksum file, the frozen plans, and every result file are in the repository; \ref{app:files} lists the files and commands that reproduce each result. The Weija records belong to the deployment team and are available from the corresponding author on reasonable request.
\end{itemize}
